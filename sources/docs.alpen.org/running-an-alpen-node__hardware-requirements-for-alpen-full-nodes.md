# Hardware requirements for Alpen full nodes

Running an Alpen Testnet III full node requires a Windows, Linux, or macOS instance with the following minimum specifications:

* CPU: 64-bit processor with at least 2c/4t, with preference for modern high-performance single-core CPUs
* Memory: 16GB
* Storage: 200GB NVMe SSD. Locally attached preferred, cloud block storage ok with ≥3,000 IOPS
* Network: stable 25 Mbps
