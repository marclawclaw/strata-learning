# Get started

Welcome to the Alpen Testnet community!

To get started, here are the details you'll need:

## Wallets <a href="#wallets" id="wallets"></a>

Alpen is an EVM-compatible blockchain that will work with EVM wallets out of the box. You can therefore use any EVM wallet that supports adding custom networks, or that natively supports Alpen. Here are a few that are known to work:

* [Enkrypt](https://www.enkrypt.com/)
* [MetaMask](https://metamask.io/)
* [Safe](https://app.safe.protofire.io/welcome)
