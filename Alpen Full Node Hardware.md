# Alpen Full Node Hardware

Minimum for a Testnet III [[Alpen Full Node]] (Linux, macOS or Windows):

- **CPU**: 64-bit, ≥2 cores / 4 threads. Strong single-core performance is preferred.
- **RAM**: 16 GB
- **Storage**: 200 GB NVMe SSD. Local disk preferred; cloud block storage is OK at ≥3,000 IOPS.
- **Network**: a stable 25 Mbps
- Software: Docker Engine 29.x or newer, and Git.
